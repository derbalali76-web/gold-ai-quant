# دمج مواصفات V2 مع MASTER PLAN

V2 مكمّلة وليست بديلاً. الترتيب الموحّد:

| مرحلة V2 | يقابل MASTER | المحتوى | الحالة |
|---|---|---|---|
| A الأساس وربط البيانات وجودة المصادر | P0–P2 | عقد البيانات، DEMO، بوابات الجودة، ثم مزوّدو Twelve Data / xaus.com / FRED / CFTC | الأساس منجز؛ **المزوّدون الحيّون لم يُربطوا** (الشبكة هنا تمنعهم) |

| E المحركات التجريبية (Micro-Edge، Information Value) | P5 | تُفعَّل فقط إذا أثبتت قيمة إضافية خارج العينة مع تصحيح الاختبارات المتعددة | مخطط |
| F اختبار شامل + أداء + APK نهائي | P5–P6 | backtester، تداول ورقي، تقرير خارج العينة | مخطط |

## قاعدة تفعيل أي محرك (E)
1. يُختبر منفرداً (walk-forward مُنقّى).
2. يُقاس **الفرق** في Brier متعدد الفئات والقيمة المتوقعة بعد التكاليف عند إضافته للنظام (ablation).
3. يُفعَّل فقط إن تحسّن الأداء بفاصل ثقة لا يشمل الصفر على فترة لم تُستخدم في التطوير.
4. أي تعديل للنموذج يحمل رقم إصدار جديد ولا يُفعَّل أثناء التداول الورقي دون إعادة الاختبار.
