# ADR-002: الصدق في البيانات والاحتمالات

**الحالة:** مقبول — 2026-11-12

**القرار:**
1. وضع DEMO يستخدم بيانات اصطناعية حتمية (seed ثابت) ويُوسم في كل استجابة: `mode="DEMO"`, `spot_or_proxy="SYNTHETIC"`، وتعرضه الواجهة بشريط واضح.
2. `probability_target_before_stop` يبقى `null` إلا إذا تحققت كل الشروط: بيانات حقيقية (ليست DEMO)، معايرة خارج العينة بتحقق walk-forward مع purge/embargo، عدد عينات معايرة ≥ 300، و Brier أفضل من معدل الأساس. وإلا تعرض الواجهة «غير متاح بعد».
3. مقاييس النموذج على البيانات الاصطناعية تُعرض في `/model-metrics` فقط مع وسم أنها اختبار آلية وليست دليلاً على أداء السوق.
4. أي سعر أقدم من الحد المسموح ⇒ UNAVAILABLE. لا يُعرض قرار مخزَّن على أنه حديث (`valid_until_utc`).
5. لمس TP وSL في نفس الشمعة ⇒ يُحتسب SL أولاً (افتراض متحفظ).
