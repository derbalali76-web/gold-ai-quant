# ADR-004: منهجية التحقق والنموذج الأساسي

**الحالة:** مقبول — 2026-11-12

**القرار:**
- الهدف: احتمال بلوغ TP قبل SL خلال الأفق (triple-barrier).
- النموذج الأول: انحدار لوجستي منتظم (baseline) فوق ميزات as-of فقط، يُقارن مع معدل الأساس.
- التحقق: walk-forward مُنقّى (purge بطول الأفق + embargo)، وفترة اختبار نهائية لا تُلمس أثناء التطوير.
- المقاييس: Brier، منحنى المعايرة، معدل الإصابة، profit factor، القيمة المتوقعة بعد التكاليف، أقصى تراجع، معدل الامتناع، فواصل ثقة (Wilson/bootstrap)، والتحذير عند صغر العينة.
- لا يُختار عتبة لاحقاً لإظهار 95%. أي عتبة تُثبت قبل لمس فترة الاختبار النهائية.
