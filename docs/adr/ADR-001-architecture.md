# ADR-001: البنية — خادم Python محلي + تطبيق Android أصلي خفيف

**الحالة:** مقبول — 2026-11-12

**السياق:** التحليل الكمي (pandas/sklearn) ثقيل على الهاتف، ولا يوجد خادم سحابي مجاني دائم بلا بطاقة ائتمان.

**القرار:**
- محرك التحليل في Python (FastAPI) يعمل على حاسوب المستخدم.
- تطبيق Android بـ Kotlin + Jetpack Compose، شاشة واحدة، بلا مكتبات شبكة خارجية (HttpURLConnection + org.json) لتقليل الحجم.
- عقد JSON واحد مُرقَّم بالإصدار (`schema_version`) يُتحقق منه بصرامة في الطرفين.
- إن تعذّر الوصول للخادم: الحالة UNAVAILABLE مع السبب. لا يُنتج الهاتف إشارات بنفسه.

**العواقب:** يجب أن يكون الحاسوب يعمل وعلى نفس الشبكة. لا وعد بتوفر دائم.
