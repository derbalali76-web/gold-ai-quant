# ADR-003: أمان الشبكة بين الهاتف والخادم المحلي

**الحالة:** مقبول — 2026-11-12

**السياق:** الخادم على الحاسوب داخل الشبكة المنزلية، وشهادات TLS لعنوان IP محلي غير عملية لمستخدم عادي.

**القرار:**
- HTTPS مسموح لأي عنوان.
- HTTP غير المشفر مسموح **فقط** لعناوين خاصة (10.x, 172.16-31.x, 192.168.x, 127.x, 10.0.2.2 للمحاكي) — يُفرض في كود التطبيق (`UrlPolicy`) قبل أي طلب، ويُختبر بوحدة اختبار.
- الخادم يقرأ فقط ولا يملك أي وظيفة تنفيذ صفقات. لا أسرار في التطبيق؛ مفاتيح المزوّدين المجانية تبقى في متغيرات بيئة على الحاسوب.
- إذن الشبكة الوحيد: `INTERNET`.
