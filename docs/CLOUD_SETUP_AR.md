# تشغيل GOLD AI QUANT على السحابة مجاناً (دون حاسوب يعمل باستمرار)

## الفكرة
| الجزء | أين يعمل | التكلفة | ماذا يفعل |
|---|---|---|---|
| جمع البيانات والتدريب | GitHub Actions (مستودع **خاص**) | ضمن الدقائق المجانية الشهرية | كل ساعة: يجمع الأسعار والأسواق المرتبطة وDukascopy وFRED/COT/GLD. كل 4 ساعات: يدرّب ويتحقق. يومياً: تقارير الدقة والإعدادات. |
| خادم «ماذا أفعل؟» | Render (خطة Free) | مجاني | يحمّل البيانات والنماذج المدرَّبة من المستودع، ويجلب السعر الحي، ويصدر القرار. لا يدرّب شيئاً على الطلب. |
| التطبيق | هاتفك | مجاني | يتصل عبر HTTPS بعنوان Render. |

**حدود صريحة للخطط المجانية:**
- Render Free: الخادم ينام بعد 15 دقيقة دون طلبات، وأول ضغطة بعدها تحتاج قرابة دقيقة. الذاكرة 512MB. التطبيق ينتظر حتى 100 ثانية ويعرض «الخادم يستيقظ».
- GitHub Actions: المواعيد المجدولة قد تتأخر وقت الضغط على المنصة. تتوقف المهام المجدولة بعد 60 يوماً دون نشاط، لكن الالتزام الآلي كل ساعة يُعدّ نشاطاً.
- الخطة المجانية لـ Twelve Data: 800 طلب يومياً، للاستخدام الشخصي فقط. لهذا يجب أن يكون المستودع **خاصاً**، فلا تُنشر البيانات علناً.

## الخطوات (مرة واحدة، نحو 20 دقيقة)
1. **GitHub:** أنشئ مستودعاً **خاصاً** وارفع إليه محتوى المشروع.
2. **مفاتيح المستودع** (Settings ← Secrets and variables ← Actions):
   - `TWELVEDATA_API_KEY`: مفتاحك المجاني.
   - `RENDER_URL`: عنوان خدمتك، مثل `https://gold-ai-quant.onrender.com` (بعد الخطوة 4).
3. **تاريخ البيانات:** من تبويب Actions شغّل `cloud-data-and-models` يدوياً باختيار `backfill` و`years=3`. يحتاج وقتاً، ثم شغّل `train`.
4. **Render:** New ← Blueprint ← اختر المستودع، فيقرأ `render.yaml`. أدخل المتغيرات التالية:
   - `TWELVEDATA_API_KEY`
   - `GOLDQUANT_TOKEN`: كلمة سرية طويلة من اختيارك.
   - `GOLDQUANT_DATA_REPO`: مثل `youruser/gold-ai-quant`.
   - `GOLDQUANT_REPO_TOKEN`: رمز GitHub من نوع fine-grained، بصلاحية **قراءة Contents فقط** لهذا المستودع وحده.
5. **التطبيق:** الإعدادات ← العنوان `https://<اسم-خدمتك>.onrender.com` والرمز السري نفسه ← حفظ.
6. **التقويم الاقتصادي:** حدّث `config/calendar.json` أسبوعياً من الهاتف مباشرة عبر واجهة GitHub الويب. بدونه لا تُصدر إشارات حية، وهذه حماية مقصودة.

## التحقق
- `https://<خدمتك>.onrender.com/health`: يُظهر `cloud.last_sync_ok` وتاريخ آخر نموذج مدرَّب.
- `/data-status`: حالة كل مصدر وآخر جلب.
- `/research/setups` و`/research/feature-upgrade` و`/research/precision`: النتائج على بياناتك الحقيقية.

## الخصوصية والأمان
- الخادم لا يملك أي صلاحية تنفيذ أو كتابة: رمز GitHub للقراءة فقط، ولا اتصال بأي وسيط.
- الرمز السري `GOLDQUANT_TOKEN` يمنع الغرباء من استهلاك حصتك المجانية.
